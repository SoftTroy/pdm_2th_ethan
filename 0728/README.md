## 4. 이 문제들이 겨냥하는 함정

- `words[1]` 은 값, `words[1:2]` 는 리스트 — 결과의 **종류**가 다름
- `"data.CSV"` — 정리(lower) 없이 `endswith(".csv")` 하면 놓침
- `result = ch + result` — 붙이는 **방향**이 순서를 뒤집음
- `break` 가 `print` **앞이냐 뒤냐**에 따라 마지막 값 포함 여부가 갈림
- 평균 이상 필터링은 **반복 두 번** 필요 (평균을 먼저 알아야 비교 가능)
- `range(1, len(t))` 로 돌며 `t[i]` vs `t[i-1]` — 0부터 돌면 `t[-1]` 과 비교하는 버그
